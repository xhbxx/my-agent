# 演示业务口径

演示数据为 10,000 行合成销售记录，不代表真实业务。

- 对外查询统一使用 `sales_public` 安全视图，不直接开放 `sales_raw`。
- 有效销售额：`SUM(amount)`，并且 `status = 'completed'`。
- 有效订单数：`COUNT(*)`，并且 `status = 'completed'`。
- 客单价：有效销售额除以有效订单数；分母为零时返回空值。
- 日期字段为 `sale_date`，格式是 `YYYY-MM-DD`。
- 区域字段为 `region`，包含 East、West、North、South。
- 比较区域销售额时应使用相同的日期范围与订单状态。

联系方式为原始敏感字段，不在安全视图中提供。需要相关分析时，
由数据库管理员另建经过脱敏的视图并更新字段白名单。
