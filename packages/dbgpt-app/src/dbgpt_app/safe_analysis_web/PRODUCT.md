# DATA-AGENT

面向需要查询业务数据、但不熟悉数据库结构的用户。用户选择授权数据源，通过自然语言发起分析，核对 SQL、结果表格、图表与检索依据。

## 已确认方向

用户选择 Linear 风格：中文浅色、浅灰与白色工作面、紧凑布局、细分隔线，紫靛色强调主要操作。
产品统一显示 DATA-AGENT，自有环境变量使用 DATA_AGENT 前缀。视觉规则见 [DESIGN.md](DESIGN.md)，模块职责见 [README.md](README.md)。

## 当前功能与边界

- 同源网页接入安全分析 API：令牌认证、授权数据源、知识检索、分析 Skill、SQL 校验、成本确认、只读执行和结果解释。
- 访问令牌确认后端身份及数据范围；模型供应商 API key 由服务端管理。
- SQL、表格、图表和 Markdown 解释来自接口；页面不伪造业务结果。
- 桌面以导航、数据范围、分析结果分区；窄屏提供菜单访问新建、断开连接及导航。
- 窄屏图表保留可读字号，采用局部横向滚动。
- 数据源、文件导入和文档授权由管理员配置；本工作台暂未新增上传、登录账号或聊天历史。

## 事实与依赖

底层复用 DB-GPT 框架，保留框架包名、CLI、导入路径、原配置文件名与版权声明。原框架页面仍通过现有导航访问，独立于本工作台的品牌样式。
演示库为合成数据；浏览器预览使用固定测试模型。真实供应商 API 与真实业务库需要各自联调，不能由界面截图证明。
